## 1. Laya가 뭔가

- 오픈소스 AI 모델. 라이선스 Apache-2.0 (무료, 상업 이용 가능).
- 개발자: Nandakishor M (인도).
- ChatGPT처럼 글을 "생성"하는 모델이 아님. 글을 읽고 **판단만** 하는 모델.
- 한 번의 계산으로 답이 나옴 → 빠름. GPU 기준 질문 1개 약 33ms.
- 100개 이상 언어 지원 (다국어 모델 `laya-multilingual` 사용 시).

### 할 수 있는 일 3가지

| 종류 | 설명 | 영업 활용 예 |
|---|---|---|
| choice (선택) | 보기 중 하나 고르기 | "이 메일은 견적요청 / 클레임 / 단순문의 중 무엇?" |
| score (점수) | 1~N 등급 매기기 | "이 불만의 심각도는 1~5 중 몇?" |
| noul (참/거짓) | 예/아니오 확률 | "이 메일에 납기 지연 언급이 있나?" |

### 모델 3종

| 모델명 | 크기 | 용도 |
|---|---|---|
| laya | 421M 파라미터 | 영어 |
| laya-multilingual | 322M 파라미터 | 100개 이상 언어 (한국어 포함 예상) |
| laya-typed-decisions | 421M 파라미터 | 분류/판단 업무 특화 |

세 모델 파일 합계 약 2.3GB. 첫 실행 시 자동 다운로드.

## 2. 노트북 설치 가능 여부 → 가능

- 지원 OS: Windows, macOS, Linux 모두.
- GPU 없어도 동작 (CPU 모드). 속도만 느려짐 (질문 1개 약 0.05~0.5초).
- 필요 조건
  - Python 3.10 이상
  - 디스크 여유 약 3GB
  - RAM 8GB 이상 권장 (공식 최소치 미기재)
  - 첫 실행 시 인터넷 연결 (모델 다운로드). 이후 오프라인 가능.

### 설치 절차 (Windows 기준)

1. Python 설치: https://www.python.org/downloads/ → 설치 시 "Add Python to PATH" 체크
2. 명령 프롬프트(cmd) 열기
3. 아래 명령 입력

```
python -m venv laya-env
laya-env\Scripts\activate
python -m pip install laya
```

4. 설치 확인

```
python -c "import laya; print(laya.__version__)"
```

5. 첫 테스트 (영어 예시)

```
laya --predict "Customer says the delivery is 3 days late and wants a refund."
```

### 추가 설치 옵션 (필요 시)

- `pip install "laya[serve]"` → 사내 HTTP 서버로 띄우기
- `pip install "laya[mcp]"` → Claude 등 AI 도구와 연결(MCP)
- `pip install "laya[onnx]"` → CPU 속도 개선

## 3. 주의점

- 개발자용 도구. 클릭해서 쓰는 프로그램 아님. 명령창 조작 필요.
- 성능 수치는 개발자 자체 발표. 독립 검증 없음.
- 한국어 정확도는 직접 테스트 필요.
- 메모리 절약: `Router(max_loaded=1)` 설정 시 모델 1개만 메모리에 올림.

## 4. 다음 단계

- PC 교체 후 설치 시, 노트북 사양(OS, RAM, GPU 유무) 알려주면 단계별 안내.
- 덕지산업 실제 이메일 샘플로 분류 정확도 테스트 추천.
